## Как запустить в PyCharm

1. Откройте папку `aytis-project` через **File → Open**
2. Правой кнопкой на `domain-manager.html` → **Open In → Browser**
3. Или: откройте файл и нажмите на иконку браузера в правом верхнем углу редактора

Серверная часть **не нужна** — это статический сайт.

## Структура проекта

```
aytis-project/
│
├── domain-manager.html      ← Точка входа. Вся HTML-разметка приложения.
│                              Подключает CSS и JS в правильном порядке.
│
├── css/
│   ├── tokens.css           ← CSS-переменные: цвета, шрифты, отступы, радиусы.
│   │                          Это "единый источник правды" для дизайна.
│   │                          Меняя переменные здесь — меняешь весь вид сайта.
│   │
│   ├── base.css             ← CSS-сброс. Убирает стандартные стили браузера,
│   │                          задаёт нормализацию поведения элементов.
│   │
│   ├── layout.css           ← Сетка приложения: .app (grid), .sidebar,
│   │                          .topbar, .main, адаптивность.
│   │
│   └── components.css       ← Все UI-компоненты: KPI-карточки, таблицы,
│                              кнопки, формы, бейджи, модальные окна, toasts.
│
├── data/
│   └── db.js                ← «База данных» в памяти браузера.
│                              В реальном проекте — REST API или БД.
│                              Массивы: domains, clients, requests,
│                              contracts, payments, activity.
│
└── js/
    ├── utils.js             ← Чистые вспомогательные функции:
    │                          daysUntil(), fmtDate(), fmtMoney(),
    │                          domainBadge(), showToast() и другие.
    │
    ├── app.js               ← Главный модуль. Переключение страниц,
    │                          тёмная тема, мобильное меню, поиск,
    │                          инициализация приложения (DOMContentLoaded).
    │
    └── pages/               ← Один файл = одна страница приложения
        ├── dashboard.js     ← KPI, алерты, таблица продлений, лента событий
        ├── domains.js       ← Таблица доменов + CRUD (добавить/изм./удалить)
        ├── clients.js       ← Таблица клиентов + CRUD
        ├── requests.js      ← Таблица заявок + создание/закрытие
        ├── payments.js      ← Платежи + подтверждение
        └── reports.js       ← Сводные карточки + экспорт CSV
```

## Архитектурные решения

### Разделение ответственности (Separation of Concerns)
Каждый файл отвечает строго за одну задачу:
- CSS не содержит логики → JS не содержит стилей
- Данные (db.js) отделены от отображения (pages/)
- Утилиты (utils.js) не зависят от структуры страниц

### CSS Custom Properties (переменные)
Все цвета и отступы — через переменные в `tokens.css`.
Тёмная тема переключается одним атрибутом `data-theme="dark"` на `<html>`.

### Модульная структура JS
```
db.js → utils.js → pages/*.js → app.js
```
Каждый следующий файл может использовать функции предыдущих.
Порядок подключения в HTML критичен.

### CRUD-операции
Функции в `pages/domains.js`:
- `renderDomains()` — чтение (Read)
- `openDomainModal(id)` — открыть форму
- `saveDomain()` — создание (Create) или обновление (Update)
- `deleteDomain(id)` — удаление (Delete)
